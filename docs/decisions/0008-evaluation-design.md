# 8. A fair comparison with a single agent

*Decided 21 October 2026.*

**The problem.** To show the team is worth having, it must be compared with something
simpler, on incidents it was never tuned on, with nothing else different.

**What we chose.** A single agent with the same tools, AI model, budget and rules for
deciding, answering in one go. Ten incidents were kept aside while building; only they
count. Each incident is run three times per system, because the AI gives slightly
different answers each time. A run scores as right if it names the true cause, or says "we
can't tell" when the evidence really can't tell. We also measure how often each system is
confidently wrong, how much of the key evidence it cites, and what each run costs.

**The cost.** Ten incidents we wrote ourselves give a direction, not proof.
